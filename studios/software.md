# Software studio

For app, system and tools developers, and accessibility specialists.

## What the studio makes

- Themes and lock screens.
- Tools for owners and repairers.
- Accessibility reviews of the Lab and the site: keyboard use, screen readers, contrast and motion.

## What we give you

- The theme, lock screen and wallpaper specs.
- Early access to new features in the Lab so you can check them before they go live.

Ask in #software-studio for the latest files.

## How work is judged

Each brief lists what it needs to do and how it's checked. Code is reviewed by the studio's maintainers, and anything that runs on a phone also gets a second review from the team.

## What's next

More of the phone's software as it comes together: system apps, camera presets and the tools that keep a phone up to date.
